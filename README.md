# Питание Москва

Сервис-концепция доставки комплексных обедов: четыре блюда за 390 ₽, напиток без доплаты, доставка 0 ₽ с 12:00 до 13:00. Каталог, выбор блюд, корзина, адрес, демонстрационное оформление, дизайн-система и адаптивный интерфейс.

## Сайт

https://awave21.github.io/eatmeat/

GitHub Pages — публичная демонстрация. Заказы сохраняются только в sessionStorage текущего браузера, контактные данные не отправляются. Кухня, курьеры и оплата не подключены. Используйте вымышленные контакты.

## Локальный запуск Pages

Требуется Node.js 22.13+.

```sh
npm ci
npm run build:pages
npm run preview:pages
```

Откройте адрес сервера с путём `/eatmeat/`. Дизайн-система доступна по `/eatmeat/design-system/`.

## Публикация

Каждый push в main запускает `.github/workflows/pages.yml`: сборка Vite и публикация GitHub Pages. В Settings → Pages выбран источник GitHub Actions.

## Серверная версия

Исходники исходной React/Vinext/Cloudflare Worker версии сохранены: `npm run dev`, `npm run build`, `npm start`. Серверный `/api/orders` использует Cloudflare D1. Для отдельного развёртывания нужна собственная конфигурация хостинга и база, привязка исходного Sites-проекта автоматически не переносится. GitHub Pages серверный API не запускает.

## Дизайн

`DESIGN.md`, `docs/` и `/design-system/` описывают цвета, компоненты и взаимодействия. Изображения сгенерированы. Фотографии блюд и напитков — PNG с прозрачностью.
